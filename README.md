# adventurers-codex
A small D&amp;D-inspired rules API built as a cloud/DevOps learning project

The application itself is deliberately simple. The main purpose of
the project is to demonstrate:

- Python development
- Linux
- testing
- databases
- Docker
- cloud infrastructure
- Infrastructure as Code
- CI/CD
- monitoring and observability
- incident investigation and recovery

The project will be developed incrementally, with operational incidents
deliberately introduced and documented as part of the learning process.
